# insigoo SIA · 互联网公益项目逻辑自洽性百项快检观察

本仓库是研究报告《互联网公益项目逻辑自洽性百项快检观察——基于 insigoo SIA 社会影响力评估框架的腾讯公益平台 100 个项目扫描》（2026年8月）的配套数据包，支撑报告全部统计数字的可复算、可检验。

## 仓库内容

```
├── 互联网公益项目逻辑自洽性百项快检观察_发表版.md   # 报告全文
├── sia_100_compute_public.py                        # 统计复算脚本（运行即复算报告全部数字）
├── data/
│   └── sia_100_stats_public.json                    # 100个项目逐维评分与汇总统计（脚本产物）
├── evidence/
│   └── evidence_public.md                           # 第三批61个项目逐条证据块 + 落选项目匿名记录
└── charts/                                          # 报告全部图表源文件（PNG）
```

## 快速复算

```bash
python sia_100_compute_public.py
```

运行后将在 `data/` 下重新生成 `sia_100_stats_public.json`，并打印：总平均分（4.97/10）、分档（21/76/3）、五大类目统计、十维度通过率、优先推进项目清单——与报告第三章至第五章一一对应。

## 计分口径

统一加权制：✅=1分，⚠️=0.5分，❌=0分，满分10分。
分档：≥6分=优先推进；3-5.5分=补充复评；<3分=暂不推荐。
（第一批14项早期评分曾采用"✅计数制"，仅作历史对照，见 JSON 中 `published_caliber_reference` 字段及报告2.4节。）

## 数据脱敏政策

为保护被评机构，本公开数据包做了两级匿名化：

1. **样本内3个低分项目（<3分）**：项目名称与机构不予公开，以匿名编号 **L1/L2/L3**（与报告附录B对应）保留其类目与逐维评分符号，全部统计可完整复算。
2. **落选项目（未进入100项样本）**：名称与机构全部匿名（D1-D13编号），保留类目、得分与落选原因。

评估仅基于项目公开页面信息，仅反映逻辑自洽性维度的披露质量，不构成对项目执行效果、资金使用效率或机构整体能力的评价。

## 机构复核

被评项目所属机构如对评分有异议，或希望提交补充材料申请复评，请通过本仓库 **GitHub Issues** 提交，我们将依据留痕证据块复核并公开更正（如有）。
